# INSOFT 新员工入职指南

版本：v2.3　　生效日期：2026-09-01　　归口部门：人力资源部

## 一、入职当天流程

1. **09:30 前台报到**：携带身份证原件、学历证书复印件、体检报告（三甲医院，3 个月内有效）。
2. **10:00 签订劳动合同**：一式两份，试用期 3 个月（校招 6 个月）。合同期限首次为 3 年。
3. **11:00 IT 领用设备**：笔记本电脑、门禁卡、动态令牌。设备押金 2000 元，离职时退还。
4. **14:00 部门见面会**：直属上级介绍团队成员，指定入职引导人（Buddy）。
5. **16:00 安全培训**：必须完成《信息安全手册》在线课程并通过 80 分以上考试，否则无法开通内网权限。

## 二、账号与权限开通

| 系统 | 开通时间 | 申请方式 |
|---|---|---|
| 企业邮箱 | 入职当天 | IT 自动开通 |
| OA 审批系统 | 入职当天 | IT 自动开通 |
| BiSheng 智能体平台 | 入职第 3 天 | 直属上级在平台内提交「成员加入」申请 |
| 代码仓库 GitLab | 按岗位 | 部门负责人在权限系统申请 |
| 生产环境堡垒机 | 转正后 | 需部门总监 + 安全部双审批 |

## 三、试用期考核

- 第 1 个月：业务知识学习，输出学习报告。
- 第 2 个月：独立完成至少一个中等复杂度任务。
- 第 3 个月：转正答辩，评委为直属上级、跨部门评委、HR。
- 答辩未通过可申请延长试用期一次，最长 3 个月。

## 四、常见问题

**Q：试用期工资打折吗？**
A：不打折。试用期工资为转正工资的 100%，且不得低于当地最低工资标准。

**Q：年假怎么算？**
A：按累计工龄计算，1 年以上不满 10 年为 5 天/年，10 年以上不满 20 年为 10 天/年。入职当年按剩余月份折算。

**Q：忘记打卡怎么办？**
A：每月有 3 次补卡机会，在 OA 提交「考勤异常申诉」，需直属上级审批。
